# 📦 Baobab

![](https://velog.velcdn.com/images/jeunghun2/post/c0c76286-3e65-4416-a7df-fd539c2b849b/image.png)

## 💡 Topic
- 창고 보관을 통해 편리한 물품 보관과 물품 이동 솔루션을 제공하며, 중고 거래를 통해 효율적인 자원 활용과 지속 가능한 소비를 실현하는 서비스
- 물품은 입고 신청 전에 카메라로 전반적인 형태를 촬영하며, 특히 흠집이나 손상 등 하자가 있는 경우 이를 별도로 상세히 기록하고 이를 통해 창고 입고 이후 발생할 수 있는 분쟁이나 문제를 사전에 방지할 수 있음
- 사용자는 AR 기능을 활용해 대상 물품을 캡처할 수 있으며, 이후 서비스 내에서 이를 실시간으로 확인할 수 있어 물품의 상태를 손쉽게 모니터링할 수 있음
- 특히 중고 물품 구매자는 단순히 사진으로만 물건을 확인하는 것을 넘어, AR 기능을 통해 물품의 크기와 형태를 360도로 세밀하게 탐색 가능. 이를 통해 제품에 대한 이해도와 신뢰도가 높아져 구매 결정 시 더욱 정확한 판단을 내릴 수 있음

<br>

## 🙋‍♂️ Part
iOS 어플리케이션 기획, 설계, 개발 (기여도 100%)
